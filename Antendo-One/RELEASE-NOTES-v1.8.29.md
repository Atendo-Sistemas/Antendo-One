# Release v1.8.29 — Subtítulos do menu em desktop e celular

O menu empresarial agora apresenta os grupos Operação, Gestão e Configurações tanto no desktop quanto no menu móvel. No desktop, os grupos continuam disponíveis como menus suspensos; no celular, os subtítulos aparecem acima de cada conjunto de opções, mantendo a navegação organizada e legível.

Validações: TypeScript sem erros, invariantes de navegação aprovados e verificação de whitespace concluída.
