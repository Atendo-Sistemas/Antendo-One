# Atendo One v1.8.16

A navegação do Super Admin foi simplificada sem criar um novo nome para a faixa superior. O texto **Prioridade** foi removido, assim como o rótulo mobile **Acesso prioritário**. Permanecem apenas os acessos diretos **Início** e **Central**, seguidos pelos grupos de navegação com submenus.

A configuração continua disponível exclusivamente no grupo **Configurações**, evitando repetição. A Central não aparece novamente no grupo Operação.
