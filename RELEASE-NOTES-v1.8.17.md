# Atendo One v1.8.17

Corrigido o menu desktop do Super Admin para que os submenus de SaaS, Operação, Controle e Configurações possam aparecer fora da faixa principal. O contêiner específico do Super Admin deixou de usar `overflow-x-auto`, que estava recortando visualmente os dropdowns mesmo quando o estado de abertura era alterado.

As demais funções, grupos, acesso mobile, PostgreSQL, volumes e configurações de autenticação permanecem inalterados.
