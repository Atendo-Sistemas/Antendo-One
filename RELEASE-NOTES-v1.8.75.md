# Atendo One v1.8.75 — análise de duplicidades no Super Admin

Corrige o aviso “Empresa não identificada” exibido ao abrir a verificação de duplicidades no painel de usuários do Super Admin. A tela agora carrega as empresas autorizadas e exige a seleção de uma empresa antes da consulta. Usuários empresariais continuam usando automaticamente a própria empresa, e o backend mantém o isolamento entre tenants.
