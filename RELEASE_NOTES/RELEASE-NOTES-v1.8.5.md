# Atendo One v1.8.5

## Central de Operação

A versão adiciona uma central com onboarding, pendências de configuração, indicadores operacionais, health check, importação CSV de clientes e exportação CSV de clientes e orçamentos.

Também foram adicionados testes de regressão para a central, navegação e fluxo de dados. O guia operacional foi atualizado com o procedimento de preparação de uma nova empresa.

## Prontidão

Lint, suíte completa e build aprovados. Não foi executado deploy, alteração de banco de produção ou uso de credenciais externas.
